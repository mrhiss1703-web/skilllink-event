# SkillLinkTV

Website tĩnh bằng HTML, CSS và JavaScript, không cần cài thư viện.

Mở `dist/index.html` để xem trực tiếp, hoặc chạy `python -m http.server 8080 --directory dist` rồi truy cập http://localhost:8080.

Ảnh và video gốc được sao chép vào `dist/assets`. Nội dung trang nằm trong `dist/index.html`, giao diện trong `dist/style.css`, thư viện ảnh và menu trong `dist/app.js`.
